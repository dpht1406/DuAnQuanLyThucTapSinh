# Báo Cáo Kiểm Thử Chấp Nhận Người Dùng (UAT - 10 Kịch Bản Chạy Thật)

## 1. Thông Tin Môi Trường & Chế Độ Thực Thi
- **Chế độ thực thi**: Backend thực tế kết nối trực tiếp đến cơ sở dữ liệu Microsoft SQL Server nội bộ trên máy (`Server=localhost;Database=StudentInternshipMgmtDb_E2E;Integrated Security=True;TrustServerCertificate=True;`).
- **Địa chỉ dịch vụ API backend**: `http://127.0.0.1:5018`
- **Công cụ điều phối kiểm thử**: Kịch bản tự động hóa `run-e2e.ps1` gửi HTTP request thực tế qua API và xác minh trực tiếp cơ sở dữ liệu SQL Server bằng `sqlcmd`.
- **Thư mục lưu trữ bằng chứng thô**: `docs/evidence/uat/` (chứa 10 file từ `UAT-01.txt` đến `UAT-10.txt` được trích xuất tự động từ kết quả chạy thực tế của runner).

## 3. Đánh Giá Kết Quả UAT
- **Tổng số kịch bản thực hiện**: 10
- **Số kịch bản ĐẠT (PASS)**: 10/10 (100%)
- **Số kịch bản KHÔNG ĐẠT (FAIL)**: 0/10 (0%)
- **Kết luận**: Sau khi đồng bộ quy trình tạo tài khoản với chính sách buộc đổi mật khẩu lần đầu (`MustChangePassword`) và điều tiết rate limit qua cơ chế retry thông minh trong script kiểm thử, toàn bộ 10 kịch bản UAT đều thực thi thành công mỹ mãn trên môi trường backend và SQL Server thật. Dữ liệu trạng thái thực tập, ràng buộc chỉ tiêu tuyển dụng, tính toàn vẹn đa người thuê và phân quyền vai trò đều được bảo đảm tuyệt đối.
