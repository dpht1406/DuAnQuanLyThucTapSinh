# Checklist kiểm toán accessibility và SEO

| Hạng mục | Kiểm tra gì | Kết quả trước | Kết quả sau | File liên quan |
|---|---|---|---|---|
| Label form | Script đối chiếu `label for` với `id`/`input-id`/`inputId`, `FormField`, và nhãn truy cập của input trên 46 file Vue | Không phát hiện label mồ côi hoặc input thiếu label | 0 phát hiện trên 45 file Vue (`npm run check:labels`) | `../../frontend/scripts/check-labels.mjs`, `../../frontend/src/components/form/FormField.vue`, các view biểu mẫu |
| Tương phản | Tỉ lệ WCAG của 11 cặp chữ, viền input và focus ring; ngưỡng 4.5:1 cho chữ và 3:1 cho viền/focus | 6 cặp không đạt | 0 cặp không đạt; 11/11 cặp đạt (`npm run check:contrast`); nút “Quay lại” đo runtime 5.43:1 bằng `getComputedStyle` | `../../frontend/scripts/check-contrast.mjs`, `../../frontend/src/style.css`, các view biểu mẫu |
| Bàn phím | Dùng Tab để tới skip link và các điều khiển; Enter/Space kích hoạt nút hiện mật khẩu | Không có skip link; nút hiện mật khẩu là icon role=button và chỉ bắt Enter | Skip link và nút button/native đã được triển khai; kiểm tra tương tác thủ công | `../../frontend/src/layouts/MainLayout.vue`, `../../frontend/src/views/auth/LoginView.vue` |
| Focus | Kiểm tra focus-visible trên liên kết, nút, input, select và điều khiển tùy biến | Có `--apply-focus-ring: none` | Không còn các mẫu tắt focus đã kiểm kê; ring đạt 6.83:1 | `../../frontend/src/style.css`, các style biểu mẫu |
| Alt text | Tìm toàn bộ `<img>`, `<svg>` và ảnh nền trong `src`; xác minh ảnh mẫu không được import | Chỉ các ảnh trong HelloWorld mẫu và SVG trang trí trên login | Xem `logs/alt-audit.txt`; kiểm tra SVG trang trí được ẩn và build thành công | `../../frontend/src/components/HelloWorld.vue` (đã xóa), `../../frontend/src/assets/` (ảnh mẫu đã xóa), `../../frontend/src/views/auth/LoginView.vue` |
| SEO | Đọc title/description, metadata các route, robots.txt; đo Lighthouse Accessibility/SEO | Title cố định `QLTT`; không có description hoặc title riêng cho route | 37/37 route có title; description và robots đã cập nhật; Lighthouse chưa đo | `../../frontend/index.html`, `../../frontend/src/router/index.js`, `../../frontend/src/utils/pageTitle.js`, `../../frontend/public/robots.txt` |
| Tên truy cập | Kiểm tra tên, trạng thái và trạng thái mở của các nút biểu tượng | Avatar mobile thiếu tên rõ ràng; user menu thiếu state; nút thông báo không nêu số chưa đọc | Đã bổ sung tên/state truy cập; kiểm tra accessibility tree thủ công còn cần thực hiện | `../../frontend/src/layouts/MainLayout.vue`, `../../frontend/src/views/auth/LoginView.vue` |
| API, Logging, Fallback | Kiểm thử 500 không lộ exception, 4xx giữ message, request log không có query/body và frontend xử lý lỗi/retry | 500 trả `exception.Message`; không có request logging/retry policy nhất quán | 3 test middleware + 6 test lỗi + 2 test retry; `dotnet test`, `npm test`, build backend/frontend đều đạt; runtime log xác nhận POST login sai và GET `/api/students` không token trả 401 | `../../backend/src/StudentInternshipMgmt.Api/Middlewares/`, `../../backend/src/StudentInternshipMgmt.Infrastructure/Services/AuthService.cs`, `../../frontend/src/api/axiosClient.js`, `../../frontend/src/utils/apiError.js`, `logs/tests-api-after.txt`, `logs/api-log-after.txt` |

Ảnh minh chứng và điểm Lighthouse được để trống chờ người thực hiện chụp/đo tại `evidence/before/` và `evidence/after/`.

Runtime API tại máy cục bộ: đăng nhập username không tồn tại trả 401; `GET /api/students` không token trả 401; CORS preflight `OPTIONS /api/companies/industries` trả 204 và được log Information. Không thực hiện request nghiệp vụ 2xx cần tài khoản đã xác thực vì không có thông tin đăng nhập test được cung cấp.
